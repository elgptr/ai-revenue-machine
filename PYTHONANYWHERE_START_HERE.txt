📞 SUPPORT / TROUBLESHOOTING

If task doesn't run:
  1. Check time format: HH:MM UTC
  2. Verify Python path: python ~/ai-revenue-machine/main_pythonanywhere.py
  3. Check requirements installed: pip list

If bot doesn't respond:
  1. Verify TELEGRAM_BOT_TOKEN in config.json
  2. Check web app is running (green status)
  3. Verify webhook URL is set correctly

If articles don't publish:
  1. Check DEVTO_API_KEY is valid
  2. Check OPENAI_API_KEY has credits
  3. Review task output for errors
