DEPLOYMENT CHECKLIST (PythonAnywhere):
═══════════════════════════════════════════════════════════════

☐ Step 4: Create PythonAnywhere Account
  → Go: https://www.pythonanywhere.com
  → Click: Sign up
  → Choose: Free account
  → Fill form: username, email, password
  → Verify email
  → Login to dashboard

☐ Step 5: Run Auto-Setup Script
  → Click: Consoles (top menu)
  → Click: Bash
  → Paste & Run:
    
    curl -fsSL https://raw.githubusercontent.com/elgptr/ai-revenue-machine/master/setup_pythonanywhere.sh | bash
  
  → Wait: 2-3 minutes for setup
  → Success: See "Setup Complete!" message

☐ Step 6: Configure API Keys
  → In Bash console, run:
    
    nano ~/ai-revenue-machine/config.json
  
  → Replace empty values with your API keys:
    - openai_api_key: [paste your OpenAI key]
    - devto_api_key: [paste your Dev.to key]
    - telegram_bot_token: [paste your Telegram token]
  
  → Save: Ctrl+O → Enter → Ctrl+X

☐ Step 7: Create Scheduled Task (Daily automation)
  → Click: Tasks (top menu)
  → Click: "Create a new scheduled task"
  → Fill:
    - UTC time: 08:00
    - Command: python ~/ai-revenue-machine/main_pythonanywhere.py
  → Click: Create

☐ Step 8: Test & Verify
  → Run task manually:
    - Click: Tasks
    - Click: "Run now" button
    - Wait: 1 minute
    - Check: Output shows "✓ Track 1 completed"
  
  → Check Dev.to:
    - Go: https://dev.to/[username]
    - Should see new articles
  
  → Test Telegram bot:
    - Open: Telegram
    - Find: @income_daily_bot (or your bot name)
    - Send: /start
    - Bot should respond
