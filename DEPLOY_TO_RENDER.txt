STEP 3: Connect GitHub Repository
  - Click "Connect repository"
  - Search for: ai-revenue-machine
  - Select: elgptr/ai-revenue-machine
  - Click "Connect"

STEP 4: Configure Service
  Fill in these fields:
  
  Name: ai-revenue-machine
  
  Runtime: Python 3.10
  
  Build Command: 
    pip install -r requirements.txt
  
  Start Command:
    python main_render.py

STEP 5: Add Environment Variables ⭐ CRITICAL
  Scroll down to "Environment" section
  Click "Add Environment Variable"
  
  Add these 3 variables (copy values from config.json):
  
  Variable 1:
    Name: OPENAI_API_KEY
    Value: [YOUR_OPENAI_API_KEY]
  
  Variable 2:
    Name: DEVTO_API_KEY
    Value: [YOUR_DEVTO_API_KEY]
  
  Variable 3:
    Name: TELEGRAM_BOT_TOKEN
    Value: [YOUR_TELEGRAM_BOT_TOKEN]

STEP 6: Review & Deploy
  - Check: All settings are correct
  - Click: "Deploy"
  - Wait: Build process completes (2-3 min)
  - Status: Should change to "running" ✓
