🚀 5-STEP SETUP

════════════════════════════════════════════════════════════════════════════════

STEP 1: Prepare Repository
────────────────────────────────────────────────────────────────────────────────

✓ Your repo: https://github.com/elgptr/ai-revenue-machine
✓ Workflow file already created: .github/workflows/daily_content.yml
✓ Entry point script: main_github_actions.py

════════════════════════════════════════════════════════════════════════════════

STEP 2: Get API Keys (10 minutes)
────────────────────────────────────────────────────────────────────────────────

Get these 3 keys:

1. OpenAI API Key:
   • Go: https://platform.openai.com/api-keys
   • Click "Create new secret key"
   • Copy the key

2. Dev.to API Key:
   • Go: https://dev.to/settings/extensions
   • Click "Generate API key"
   • Copy the key

3. Telegram Bot Token (Optional):
   • Open Telegram
   • Find @BotFather
   • Send: /newbot
   • Copy bot token

════════════════════════════════════════════════════════════════════════════════

STEP 3: Add GitHub Secrets
────────────────────────────────────────────────────────────────────────────────

1. Go to: https://github.com/elgptr/ai-revenue-machine

2. Click: Settings → Secrets and variables → Actions

3. Click: "New repository secret"

4. Add EACH key:

   Name: OPENAI_API_KEY
   Secret: [paste key]
   
   Name: DEVTO_API_KEY
   Secret: [paste key]
   
   Name: TELEGRAM_BOT_TOKEN
   Secret: [paste token]

5. You should see 3 secrets listed ✓

════════════════════════════════════════════════════════════════════════════════

STEP 4: Test the Workflow
────────────────────────────────────────────────────────────────────────────────

1. Go to: https://github.com/elgptr/ai-revenue-machine
2. Click: Actions tab
3. Find: "Daily Content Generation"
4. Click: Run workflow → Run workflow
5. Wait 1-2 minutes
6. Green checkmark = SUCCESS ✓

════════════════════════════════════════════════════════════════════════════════

STEP 5: Verify
────────────────────────────────────────────────────────────────────────────────

✓ Check Dev.to: https://dev.to/[your-username]/
✓ Check GitHub Actions: Actions tab
✓ Articles should be published!
